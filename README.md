# AYDO Research public profile

[profile/README.md](profile/README.md) introduces the organization on its public
GitHub Overview. The profile describes our purpose, learning flow, focus areas,
and working principles.

## Contents

- `profile/README.md`: public introduction in Indonesian and a Mermaid learning flow.
- `profile/assets/dashboard-header.svg`: banner in the shared AYDO style, with a
  teal palette for AYDO Research.

## Maintenance

Keep this repository public and its profile on the default branch. Keep the
introduction general: describe the approach without publishing workspace
inventories, client names, project data, or discussion content. Review both
text and assets before publication.

Preserve the established banner style when updating the profile. Check relative
image links, section links, and Mermaid rendering after changes.
